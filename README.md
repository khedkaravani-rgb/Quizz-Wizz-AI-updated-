# Quizz‑Wizz‑AI 🎓✨

A project under Recurz 2026 (Genesis 6.0-ieee)

An AI‑powered quiz platform built with **React, Vite, TailwindCSS, Supabase, and TypeScript**.  
Quizz‑Wizz‑AI helps learners practice smarter by generating adaptive quizzes, tracking attempts, and highlighting misconceptions.

---

## 🚀 Features
- 🧠 **AI‑Generated Quizzes** – Questions tailored to your learning goals.
- 📊 **Progress Tracking** – Stores attempts and shows insights on misconceptions.
- 🔑 **Authentication** – Secure login with Supabase.
- 🎨 **Modern UI** – Clean pastel theme with TailwindCSS.
- ⚡ **Fast Builds** – Powered by Vite for instant development and deployment.

---

## 🛠 Tech Stack
- **Frontend:** React + TypeScript + TailwindCSS
- **Backend/Data:** Supabase + PostgreSQL
- **AI Integration:** Gemini API / OpenAI API
- **Build Tool:** Vite
- **Deployment:** Vercel

## ⚙️ Setup & Installation

1. Clone the repo:
   ```bash
   git clone https://github.com/<your-username>/quizz-wizz-ai.git
   cd quizz-wizz-ai
   ```

2. Install dependencies:
   ```bash
    npm install
   ```
3. Start the dev server:
    ```bash
    npm run dev
   ```
